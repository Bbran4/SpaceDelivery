# SpaceDelivery

**SpaceDelivery** is a space-delivery roguelike incremental idler. You work for an interstellar delivery company, hauling packages across the universe, expanding your operation, and turning each run into an opportunity to go farther than the last.

The goal is simple: take the job, deliver the cargo, get paid, upgrade your operation, and push deeper into space. The universe is enormous, and the delivery queue is not getting any shorter.

## Core gameplay

The game is built around a loop of delivery, rewards, and progression:

1. **Take on deliveries.** Accept packages and set out for destinations across the universe.
2. **Travel through space.** Manage the journey and work toward completing each delivery.
3. **Complete jobs and earn rewards.** Successful deliveries fuel your growing operation.
4. **Invest in upgrades.** Improve your delivery capabilities so future jobs become more efficient and rewarding.
5. **Push farther on each run.** Roguelike progression gives each run room to build momentum, while incremental systems reward continued growth.
6. **Repeat and expand.** Build a stronger delivery operation and work toward reaching more of the universe.

## Game pillars

- **Space delivery:** Packages, destinations, and the constant work of keeping an interstellar courier service running.
- **Incremental progression:** Earn rewards and reinvest them into upgrades that improve future performance.
- **Roguelike runs:** Each run is a chance to build momentum, make progression choices, and see how far your operation can go.
- **Idler-friendly growth:** Progression is designed around steadily improving your operation rather than relying only on constant manual input.
- **A growing universe:** The long-term fantasy is to move from routine courier jobs to operating a capable delivery service across space.

## Progression

Progression is the engine behind every successful courier business. Deliveries provide the rewards needed to strengthen your operation, and upgrades should make subsequent journeys more effective.

The main progression goals are to:

- Improve delivery speed and efficiency.
- Increase the value and output of each run.
- Unlock stronger capabilities as the operation grows.
- Build momentum through repeated runs and long-term incremental growth.
